Why is there a limit?

Irminsul is a free test build. AI-written answers run on free API tiers with no budget behind them, so they're shared fairly:

  • Your AI answers refill one at a time, like stamina, so there's always more later.
  • The shared pool refills steadily all day instead of at midnight, so players in every time zone get a turn.
  • Answers from game data are always free: stats, passives, constellations, set bonuses and repeat questions never count.

No sign-in and no tracking. The counter only remembers your connection for a while, in memory, and nothing about you is saved.
